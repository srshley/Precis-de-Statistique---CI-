1.1 Définition de la statistique

La statistique est la science qui traite de la collecte, de l'organisation, de l'analyse, de l'interprétation et de la présentation des données numériques.

Origine et rôle de la statistique

Le terme "statistique" vient du latin status qui signifie "état". À l'origine, elle servait à collecter des informations sur l'État (population, ressources, impôts). Aujourd'hui, elle est utilisée dans pratiquement tous les domaines de la connaissance humaine.

Différence entre statistique descriptive et statistique inférentielle

Analogique : La statistique descriptive est comme un photographe qui décrit ce qu'il voit. La statistique inférentielle est comme un détective qui tire des conclusions sur ce qu'il ne voit pas directement, à partir d'indices.
Critère Statistique descriptive Statistique inférentielle
Objectif Décrire et résumer un ensemble de données observé Faire des inférences sur une population à partir d'un échantillon
Méthodes Moyennes, pourcentages, graphiques, tableaux Tests d'hypothèses, intervalles de confiance, modèles de régression
Exemple concret Calculer la moyenne d'âge des étudiants d'une classe (observés) Estimer la moyenne d'âge de tous les étudiants d'une université à partir d'un échantillon de 100 étudiants
Exemple concret : Vous êtes le responsable qualité d'une usine de boulons.
  • Descriptive : Vous mesurez 1000 boulons et calculez que le diamètre moyen est de 12,3 mm avec un écart-type de 0,2 mm. Vous décrivez uniquement ces 1000 boulons.
  • Inférentielle : À partir de ces 1000 boulons, vous estimez que tous les boulons produits par l'usine ont un diamètre compris entre 11,9 mm et 12,7 mm (avec 95% de confiance).

Domaines d'application

  • Économie : Analyse du PIB, inflation, chômage, marchés financiers
  • Santé : Épidémiologie, essais cliniques, suivi des maladies
  • Éducation : Résultats scolaires, taux de réussite, évaluations
  • Sciences sociales : Opinions publiques, comportements, démographie
  • Gestion d'entreprise : Contrôle qualité, prévisions de ventes, analyse de marché

1.3 Concepts fondamentaux

Population statistique : Ensemble de tous les individus ou éléments sur lesquels on veut tirer des conclusions.
Individu statistique : Chaque élément de la population sur lequel on observe des caractéristiques.
Échantillon : Sous-ensemble de la population sélectionné pour l'étude.
Variable statistique : Caractéristique qui peut prendre différentes valeurs selon les individus.
Modalité : Valeur particulière qu'une variable peut prendre.
Analogique : Imaginez un lac rempli de poissons.
  • La population = tous les poissons du lac
  • L'individu = un seul poisson
  • L'échantillon = les poissons capturés dans un filet (une partie de la population)
  • La variable = la longueur du poisson (en cm)
  • La modalité = des valeurs possibles comme 15 cm, 20 cm, 30 cm...

1.4 Types de variables

Règle simple : Si on peut compter ou mesurer → quantitative (avec chiffres). Si on ne peut que décrire ou classer → qualitative (avec mots).

Variables qualitatives

Décrivent des qualités ou attributs qui ne peuvent pas être mesurés numériquement.

Nominales

Catégories sans ordre intrinsèque (les catégories peuvent être permutées sans perte de sens).

  • Sexe : homme, femme
  • Groupe sanguin : A, B, AB, O
  • Couleur des yeux : bleu, vert, marron
  • Nationalité, marque de téléphone, ville de résidence

Ordinales

Catégories avec un ordre logique, mais les écarts entre elles ne sont pas mesurables.

  • Niveau d'éducation : aucun, primaire, secondaire, supérieur
  • Satisfaction : très insatisfait → insatisfait → neutre → satisfait → très satisfait
  • Évaluation scolaire : insuffisant, passable, bien, très bien, excellent

Variables quantitatives

Prennent des valeurs numériques où les opérations arithmétiques ont un sens (addition, moyenne, etc.).

Discrètes

Ne peuvent prendre que des valeurs séparées, généralement des entiers (on compte, on ne mesure pas).

  • Nombre d'enfants dans une famille : 0, 1, 2, 3...
  • Nombre de voitures possédées : 0, 1, 2...
  • Note sur 20 à un examen : 10, 12, 15...
  • Nombre de défauts sur une pièce fabriquée

Continues

Peuvent prendre n'importe quelle valeur dans un intervalle (on mesure avec une unité).

  • Taille d'une personne : 1,74 m, 1,82 m...
  • Poids : 65,3 kg, 72,8 kg...
  • Temps de réaction : 0,342 s, 0,521 s...
  • Température, revenu, altitude, vitesse

1.5 Étapes d'une étude statistique

  1. Définition du problème : Formuler clairement la question que l'on cherche à résoudre. Exemple : "Quel est l'effet du nouveau engrais sur le rendement du blé ?"
  2. Collecte des données : Rassembler les informations par enquêtes, mesures ou exploitation de bases existantes.
  3. Organisation des données : Trier, classer et présenter sous forme exploitable (tableaux, graphiques).
  4. Analyse des données : Appliquer les méthodes statistiques (calculs, tests).
  5. Interprétation des résultats : Donner du sens aux résultats par rapport au problème initial.
Attention : Une mauvaise définition du problème ou une collecte de données inadéquate peut rendre inutiles même les analyses les plus sophistiquées. "Garbage in, garbage out."

Glossaire

Population statistique
Ensemble complet de tous les individus ou objets sur lesquels porte l'étude.
Échantillon
Sous-ensemble représentatif de la population, utilisé pour tirer des conclusions quand l'étude exhaustive est impossible.
Variable statistique
Caractéristique qui varie selon les individus ; peut être quantitative (numérique) ou qualitative (catégorielle).
Paramètre vs Statistique
Un paramètre (µ, s) décrit la population ; une statistique (ẍ, s) décrit un échantillon.
Fréquence
Proportion d'individus présentant une modalité donnée, soit en effectif (ni), soit en relatif (fi = ni/N).

Présentation des données brutes

Les données brutes sont les observations telles qu'elles ont été collectées, sans aucun traitement.

Tableau de données : Organisation des observations en lignes (individus) et colonnes (variables).

Effectifs

Effectif total (N) : Nombre total d'individus dans la série.

Effectif simple (ni) : Nombre de fois où une valeur particulière apparaît dans la série.

Fréquences

Fréquence simple (fi) : Rapport de l'effectif simple à l'effectif total : \(f_i = n_i / N\)

Fréquence en pourcentage : fi × 100

La somme des fréquences simples est égale à 1.
La somme des fréquences en pourcentage est égale à 100%.

2.2 Séries statistiques groupées

Construction des classes

Amplitude d'une classe (a) : différence entre la borne supérieure et la borne inférieure d'une classe.

Centre d'une classe (c_i) : moyenne des bornes inférieure et supérieure de la classe.

Choix du nombre de classes

Règle de Sturges : \(k = 1 + 3,3 \times \log_{10}(N)\)

où \(k\) est le nombre de classes et \(N\) l'effectif total.

Amplitude et densité de proportion

Amplitude (a) : différence entre la borne supérieure et la borne inférieure d'une classe.

Densité de proportion (d_i) : rapport de la fréquence à l'amplitude de la classe.

\[d_i = \frac{f_i}{a}\]

La densité de proportion est essentielle lorsque les classes n'ont pas la même amplitude : elle permet de comparer des classes de tailles différentes en ramenant la fréquence à une unité d'amplitude.

Exemple : Si une classe d'amplitude 5 a une fréquence de 20%, sa densité est 20%/5 = 4% par unité. Une autre classe d'amplitude 10 avec 30% a une densité de 30%/10 = 3% par unité. Malgré une fréquence plus faible, la première classe est plus dense.

2.3 Représentations graphiques

Pour variables qualitatives

Diagramme en barres

Chaque catégorie est représentée par un rectangle dont la hauteur est proportionnelle à l'effectif ou à la fréquence.

Diagramme circulaire (camembert)

Le cercle représente l'effectif total. Chaque secteur correspond à une catégorie, avec un angle proportionnel à l'effectif ou à la fréquence.

À retenir : Un tableau de fréquences, c'est comme le plan de rangement d'une bibliothèque. Chaque étagère (classe ou catégorie) reçoit exactement le nombre de livres (individus) correspondant. Le graphique est la photo de cette bibliothèque : on voit d'un coup d'oeil les sections les plus remplies.

Pour variables quantitatives discrètes

Diagramme en bâtons

Similaire au diagramme en barres mais utilisé pour les valeurs discrètes.

Pour variables quantitatives continues

Histogramme

Représente les fréquences (ou densités) des classes par des rectangles dont la base est l'amplitude de la classe et la hauteur est proportionnelle à la fréquence.

Polygone des fréquences

On relie les points situés au sommet de chaque rectangle de l'histogramme (abscisse = centre de la classe, ordonnée = fréquence).

Courbe cumulative (ogive)

Représente l'effectif cumulé ou la fréquence cumulée en fonction de la borne supérieure des classes.

Glossaire

Classe statistique
Intervalle [borne_inf ; borne_sup[ regroupant des valeurs continues voisines ; toutes les classes d'une série ont généralement la même amplitude.
Amplitude (a)
Largeur d'une classe : a = borne_sup - borne_inf. Essentielle pour calculer la densité de proportion.
Centre de classe (ci)
Valeur centrale d'une classe : ci = (borne_inf + borne_sup) / 2. Utilisée comme valeur représentative pour les calculs.
Fréquence cumulée
Somme des fréquences des classes précédentes y compris la classe courante ; permet de lire les effectifs « jusqu'à » une valeur.
Densité de proportion (di)
Rapport fi/a. Utile quand les classes ont des amplitudes inégales pour comparer les classes entre elles.

Cas d'application réel

Organisation des ventes d'une chaîne de magasins

Une chaîne de grande distribution analyse les montants d'achat de 10 000 clients sur une journée. Les données brutes (liste de 10 000 montants) sont impossibles à lire. En les organisant par classes de 10 € d'amplitude, elle obtient un tableau de fréquences immédiatement exploitable.

3.1 La moyenne arithmétique

Moyenne arithmétique : Somme de toutes les valeurs divisée par le nombre de valeurs.

Formule : \(\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}\) où les \(x_i\) sont les valeurs de la série et \(n\) l'effectif total.

Calcul pour une série simple

Exemple : Données : 5, 8, 12, 15, 20

Somme = 5+8+12+15+20 = 60

n = 5

Moyenne = 60/5 = 12

Calcul pour une série groupée

Pour les séries continues regroupées en classes, on utilise les centres de classe \(c_i\) comme valeurs représentatives :

\[\bar{x} = \frac{\sum_{i=1}^{k} f_i c_i}{N}\]

où \(k\) est le nombre de classes, \(f_i\) l'effectif de la classe \(i\), \(c_i\) le centre de la classe, et \(N = \sum f_i\) l'effectif total.

Rappel important : Le centre de classe \(c_i\) est la moyenne des bornes de la classe : \(c_i = \frac{\text{borne inf} + \text{borne sup}}{2}\). Par exemple, pour la classe [10 ; 20[, le centre est \(c = \frac{10+20}{2} = 15\).

Étapes du calcul :

  1. Déterminer le centre de chaque classe \(c_i\).
  2. Multiplier chaque centre par son effectif : \(f_i \times c_i\).
  3. Sommer tous les produits : \(\sum f_i c_i\).
  4. Diviser par l'effectif total : \(\bar{x} = \frac{\sum f_i c_i}{N}\).

Propriétés de la moyenne :

  • La somme des écarts à la moyenne est nulle : \(\sum (x_i - \bar{x}) = 0\)
  • Elle est affectée par toutes les valeurs de la série.
  • Elle est sensible aux valeurs extrêmes (valeurs aberrantes).

3.2 La médiane

Médiane : Valeur qui partage la série ordonnée en deux parties égales.

Détermination pour une série simple

  1. Classer les données par ordre croissant.
  2. Si le nombre d'observations n est impair : médiane = valeur centrale.
  3. Si n est pair : médiane = moyenne des deux valeurs centrales.

Détermination pour une série groupée

Pour les séries continues regroupées en classes, la médiane s'obtient par interpolation linéaire dans la classe médiane :

\[Me = L + \left(\frac{\frac{N}{2} - F}{f}\right) \times a\]

où :

  • \(L\) = borne inférieure de la classe médiane
  • \(N\) = effectif total
  • \(F\) = effectif cumulé avant la classe médiane (effectifs des classes précédentes)
  • \(f\) = effectif de la classe médiane
  • \(a\) = amplitude de la classe médiane (borne sup − borne inf)

Comment trouver la classe médiane : La classe médiane est la première classe pour laquelle l'effectif cumulé dépasse \(N/2\). En d'autres termes, c'est la classe qui contient la 50ème percentile de la distribution.

Étapes du calcul :

  1. Calculer les effectifs cumulés croissants.
  2. Trouver \(N/2\) et identifier la classe médiane (première classe dont l'effectif cumulé ≥ \(N/2\)).
  3. Identifier \(L\), \(F\), \(f\) et \(a\).
  4. Appliquer la formule d'interpolation.

Avantages de la médiane :

  • Robuste face aux valeurs extrêmes.
  • Toujours existante et unique.
  • Facile à comprendre.

Inconvénients :

  • Ne tient pas compte de toutes les données.
  • Moins précise que la moyenne lorsqu'il n'y a pas de valeurs aberrantes.

3.3 Le mode

Mode : Valeur qui apparaît le plus fréquemment dans une série.

Détermination du mode

Pour une série simple : compter les occurrences de chaque valeur.

Pour une série groupée : la classe modale est celle ayant l'effectif le plus élevé.

Particularités du mode :

  • Peut être inexistant (toutes les valeurs différentes).
  • Peut être multiple (plusieurs valeurs avec le même effectif maximal).
  • Applicable aux variables qualitatives.
  • Pas affecté par les valeurs extrêmes.

Image mentale : La moyenne, la médiane et le mode sont comme trois amis qui cherchent le centre d'une pièce. La moyenne est le centre de gravité (comme une balançoire qui s'équilibre). La médiane est la personne qui se tient exactement au milieu du groupe. Le mode est l'endroit où il y a le plus de monde. Dans une distribution parfaitement symétrique, les trois se tiennent au même endroit.

Mode pour données groupées

Pour une série groupée en classes, on détermine d'abord la classe modale (celle avec l'effectif le plus élevé), puis on interpole pour obtenir une estimation du mode :

\[Mo = L + \frac{\Delta_1}{\Delta_1 + \Delta_2} \times a\]

où :

  • \(L\) = borne inférieure de la classe modale
  • \(\Delta_1\) = différence d'effectif entre la classe modale et la classe précédente : \(\Delta_1 = f_{modale} - f_{précédente}\)
  • \(\Delta_2\) = différence d'effectif entre la classe modale et la classe suivante : \(\Delta_2 = f_{modale} - f_{suivante}\)
  • \(a\) = amplitude de la classe modale

Interprétation : Cette formule tire le mode vers la classe la plus peuplée en pondérant par les écarts d'effectifs avec les voisines. Si \(\Delta_1 > \Delta_2\), la classe précédente est moins peuplée que la suivante, donc le mode se rapproche de la borne supérieure.

Cas particuliers :

  • Si la classe modale est la première classe, on suppose \(\Delta_1 = \Delta_2\).
  • Si la classe modale est la dernière classe, on suppose aussi \(\Delta_1 = \Delta_2\).
  • Si deux classes ont le même effectif maximal, on peut calculer le mode pour chacune ou prendre le milieu des deux.

3.4 Comparaison des mesures de tendance centrale

Quand utiliser la moyenne ?

  • Lorsque les données sont symétriques et sans valeurs extrêmes.
  • Lorsque l'on veut utiliser toutes les données de la série.
  • Pour des variables quantitatives continues ou discréites avec beaucoup de valeurs.

Quand utiliser la médiane ?

  • Lorsque la série contient des valeurs aberrantes.
  • Lorsque la distribution est asymétrique.
  • Lorsque l'on cherche une valeur typique résistante aux extrêmes.

Quand utiliser le mode ?

  • Pour les variables qualitatives (nominales ou ordinales).
  • Lorsque l'on veut connaître la valeur la plus fréquente.
  • Lorsque l'on travaille avec des discrètes comportant peu de valeurs différentes.

Relation dans une distribution symétrique : Moyenne ≈ Médiane ≈ Mode

Dans une distribution asymétrique à droite : Mode < Médiane < Moyenne

Dans une distribution asymétrique à gauche : Moyenne < Médiane < Mode

3.5 Autres types de moyennes

Moyenne géométrique

Moyenne géométrique : Racine n-ième du produit des valeurs. Utile pour des taux de croissance, des ratios, ou des données multiplicatives.

\[\bar{x}_g = \sqrt[n]{x_1 \times x_2 \times \cdots \times x_n}\]

où les \(x_i\) sont les valeurs de la série et \(n\) l'effectif total.

Exemple : Un investissement rapporte +10% la première année, +20% la seconde, −5% la troisième. Le taux de croissance annuel moyen est donné par la moyenne géométrique : \(\bar{x}_g = \sqrt[3]{1,10 \times 1,20 \times 0,95} \approx 1,078\) soit +7,8% par an (et non la moyenne arithmétique 8,3%).

Moyenne harmonique

Moyenne harmonique : Inverse de la moyenne des inverses. Utile pour des vitesses, des rendements, ou des ratios.

\[\bar{x}_h = \frac{n}{\sum_{i=1}^{n} \frac{1}{x_i}}\]

où les \(x_i\) sont les valeurs de la série et \(n\) l'effectif total.

Exemple : Un trajet aller-retour : 60 km/h à l'aller, 40 km/h au retour. La vitesse moyenne est la moyenne harmonique : \(\bar{x}_h = 2 / (1/60 + 1/40) = 48\) km/h (et non 50 km/h, moyenne arithmétique).

Moyenne quadratique (RMS)

Moyenne quadratique (Root Mean Square) : Racine carrée de la moyenne des carrés. Utilisée en physique (puissance, tension) et pour mesurer la dispersion.

\[\bar{x}_q = \sqrt{\frac{\sum_{i=1}^{n} x_i^2}{n}}\]

où les \(x_i\) sont les valeurs de la série et \(n\) l'effectif total.

Exemple : Tension électrique : 2V, 4V, 6V → RMS = \(\sqrt{(4+16+36)/3} \approx 4,32\)V.

Relations entre moyennes : Pour une série de nombres positifs non tous égaux : \(\bar{x}_h < \bar{x}_g < \bar{x} < \bar{x}_q\) (inégalité de Cauchy-Schwarz).

4.1 Les quantiles

Quantile : Valeur qui partage une série ordonnée en parties égales.

Quartiles

Ils divisent la série en 4 parties égales (25% chacune).

  • Premier quartile (Q1) : 25% des données sont inférieures à cette valeur.
  • Deuxième quartile (Q2) : 50% des données sont inférieures à cette valeur (c'est la médiane).
  • Troisième quartile (Q3) : 75% des données sont inférieures à cette valeur.

Déciles

Ils divisent la série en 10 parties égales (10% chacune). Notés D1, D2, ..., D9.

Percentiles

Ils divisent la série en 100 parties égales (1% chacune). Notés P1, P2, ..., P99.

Formule générale pour le k-ième quantile (Qk) d'une série simple :

\(\text{Position} = \frac{k}{4} \times (N + 1)\) pour les quartiles (k = 1, 2, 3)

\(\text{Position} = \frac{k}{10} \times (N + 1)\) pour les déciles (k = 1, …, 9)

\(\text{Position} = \frac{k}{100} \times (N + 1)\) pour les percentiles (k = 1, …, 99)

où \(k\) est le rang du quantile et \(N\) l'effectif total. Si la position n'est pas entière, on interpole entre les deux valeurs voisines.

Calcul des quantiles pour une série groupée en classes

Pour les séries continues regroupées en classes, la méthode est analogue à celle de la médiane (interpolation linéaire) :

\[Q_k = L + \left(\frac{\frac{k \times N}{4} - F}{f}\right) \times a\]

où :

  • \(L\) = borne inférieure de la classe contenant le k-ième quartile
  • \(N\) = effectif total
  • \(F\) = effectif cumulé avant cette classe
  • \(f\) = effectif de cette classe
  • \(a\) = amplitude de cette classe

Pour les déciles, remplacer \(k \times N / 4\) par \(k \times N / 10\).
Pour les percentiles, remplacer par \(k \times N / 100\).

Étapes du calcul :

  1. Construire le tableau des effectifs cumulés croissants.
  2. Calculer la position théorique du quantile : \(\text{pos} = \frac{k \times N}{4}\) (pour un quartile).
  3. Trouver la classe qui contient cette position (première classe dont l'effectif cumulé ≥ pos).
  4. Appliquer la formule d'interpolation.

Écart interquartile (IQR) : \(IQR = Q_3 - Q_1\)

4.3 Diagramme en boîte (Boxplot)

Le boxplot représente graphiquement les quartiles, la médiane et les valeurs atypiques potentielles.

Construction d'un boxplot

  1. Calculer Q1, Q2 (médiane), Q3 et l'IQR.
  2. Tracer une boîte de Q1 à Q3.
  3. Placer un trait à l'intérieur de la boîte à la médiane (Q2).
  4. Tracer les moustaches (whiskers) :
    • Le moustache inférieure s'étend jusqu'à la plus petite valeur ≥ Q1 – 1,5×IQR.
    • Le moustache supérieure s'étend jusqu'à la plus grande valeur ≤ Q3 + 1,5×IQR.
  5. Identifier les valeurs atypiques : les points isolés au-delà des moustaches.

Lecture d'un boxplot

  • La boîte montre l'intervalle interquartile (50% central).

    Chapitre 5

    Mesures de dispersion

    Étendue, variance, écart-type et coefficient de variation

    8 sections 5 exercices et activites

    5.1 Étendue

    Étendue (R) : Différence entre la valeur maximale et la valeur minimale d'une série.

    \[R = x_{\max} - x_{\min}\]

    Avantage : Très simple à calculer.

    Limite : Ne tient compte que des deux valeurs extrêmes, ignorant le reste de la série.

    5.2 Écart interquartile (IQR)

    Écart interquartile (IQR) : Différence entre le troisième quartile et le premier quartile.

    \[IQR = Q_3 - Q_1\]

    L'IQR représente l'étendue des 50% centraux des données. Il est plus robuste que l'étendue car non affecté par les valeurs extrêmes.

    Analogie : Imaginez deux groupes d'élèves. Groupe A : notes de 8 à 18 (étendue large). Groupe B : notes de 12 à 14 (étendue faible). La moyenne peut être identique (disons 13), mais la dispersion raconte une histoire très différente : le groupe A est hétérogène, le groupe B est homogène. La dispersion mesure cette variabilité que la moyenne seule ne capture pas.

    5.3 Variance

    Variance (S² ou σ²) : Moyenne des carrés des écarts à la moyenne.

    \[\sigma^2 = \frac{\sum (x_i - \mu)^2}{N} \quad\text{(population)}\]

    \[S^2 = \frac{\sum (x_i - \bar{x})^2}{N - 1} \quad\text{(échantillon)}\]

    La variance est toujours positive ou nulle (si toutes les valeurs sont identiques).

    Interprétation : Plus la variance est grande, plus les données sont dispersées autour de la moyenne.

    Méthode de calcul simplifiée :

    \(\sigma^2 = \frac{\sum x^2}{N} - \mu^2\)

    Cette formule évite de calculer chaque écart individuel.

    Variance pour une série groupée en classes

    Pour les séries continues regroupées en classes, on utilise les centres de classe \(c_i\) :

    \[\sigma^2 = \frac{\sum_{i=1}^{k} f_i (c_i - \bar{x})^2}{N}\]

    ou, avec la formule simplifiée :

    \[\sigma^2 = \frac{\sum_{i=1}^{k} f_i c_i^2}{N} - \bar{x}^2\]

    Rappel : Le centre de classe \(c_i\) est utilisé comme valeur représentative de chaque classe. Plus la distribution est homogène à l'intérieur des classes, plus l'approximation est bonne.

    5.4 Écart-type

    Écart-type (σ ou S) : Racine carrée de la variance.

    \[\sigma = \sqrt{\sigma^2} \qquad S = \sqrt{S^2}\]

    L'écart-type s'exprime dans la même unité que les données originales, ce facilite son interprétation.

    Règle empirique (distribution normale) :

    • Environ 68% des données se situent dans l'intervalle μ ± 1σ
    • Environ 95% des données se situent dans l'intervalle μ ± 2σ
    • Environ 99,7% des données se situent dans l'intervalle μ ± 3σ

    Écart-type pour une série groupée en classes

    Pour les séries continues regroupées en classes, on calcule simplement :

    \[\sigma = \sqrt{\frac{\sum_{i=1}^{k} f_i c_i^2}{N} - \bar{x}^2}\]

    5.6 Variable centrée réduite

    Variable centrée réduite (z-score) : Transformation qui exprime chaque valeur par son écart à la moyenne, mesuré en nombre d'écarts-types.

    \[z_i = \dfrac{x_i - \mu}{\sigma}\]

    Cette transformation est utile pour :

    • Comparer des valeurs issues de distributions différentes (notes d'examens, mesures physiques, etc.)
    • Détecter des valeurs extrêmes (|z| > 3 est souvent considéré comme atypique)
    • Standardiser les données avant d'appliquer certaines méthodes statistiques

    Propriétés : Si on transforme toutes les valeurs d'une série en z-scores, la moyenne des z-scores est nulle (\(\bar{z}=0\)) et leur écart-type est 1 (\(\sigma_z=1\)).

    Mesures de forme

    Asymétrie (skewness) et aplatissement (kurtosis)

    6.1 Asymétrie (Skewness)

    Asymétrie : Mesure du degré d'asymétrie d'une distribution par rapport à son centre.

    Types d'asymétrie

    Asymétrie positive (à droite)

    La queue de la distribution s'étend vers la droite.

    • Moyenne > Médiane > Mode
    • Quelques valeurs élevées "tirent" la moyenne vers la droite.
    • Exemple : Distribution des revenus, âge des participants à un marathon.

    Asymétrie négative (à gauche)

    La queue de la distribution s'étend vers la gauche.

    • Mode > Médiane > Moyenne
    • Quelques valeurs faibles "tirent" la moyenne vers la gauche.
    • Exemple : Âge au décès dans un pays développé (la plupart des gens vivent vieux).

    Asymétrie nulle (distribution symétrique)

    • Moyenne ≈ Médiane ≈ Mode
    • Exemple : taille des adultes d'une population homogène.

    Diagnostic rapide de l'asymétrie :

    Si moyenne > médiane → asymétrie positive

    Si moyenne < médiane → asymétrie négative

    Si moyenne ≈ médiane → symétrie

    6.2 Aplatissement (Kurtosis)

    Kurtosis : Mesure de l'aplatissement d'une distribution par rapport à la distribution normale (gaussienne).

    Types de distributions

    Leptokurtique

    Distribution plus pointue que la normale (queues plus épaisses).

    • Kurtosis positive (K > 0 ou K > 3 selon la définition).
    • Plus de valeurs près du centre et plus de valeurs extrêmes que la normale.
    • Exemple : Rendements financiers (crises boursières), hauteur des vagues.

    Mésokurtique

    Distribution dont l'aplatissement est similaire à celui de la normale.

    • Kurtosis nulle (K ≈ 0 ou K ≈ 3).
    • Exemple : La distribution normale elle-même, tailles d'adultes.

    Platykurtique

    Distribution plus aplatie que la normale (queues plus fines).

    • Kurtosis négative (K < 0 ou K < 3).
    • Moins de valeurs extrêmes que la normale.
    • Exemple : Distribution uniforme, températures quotidiennes tempérées.

    Rappel (kurtosis centrée réduite) :

    Kurtosis = (Σ (x – μ)⁴ / N) / σ⁴ – 3

    Si K = 0 → mésokurtique

    Si K > 0 → leptokurtique

    Si K < 0 → platykurtique

    Image mentale : Imaginez trois montagnes. Une montagne normale (mésokurtique) a des pentes régulières. Une montagne très pointue (leptokurtique) a un sommet aigu et des falaises abruptes. Une montagne arrondie et aplatie (platykurtique) ressemble à une colline. En finance, on parle de "queues épaisses" (fat tails) pour les distributions leptokurtiques car les événements extrêmes (krachs) sont plus fréquents que ne le prédit la normale.

    3. Mésokurtique : dans une forêt homogène, la taille des arbres suit approximativement une distribution normale (symétrique et kurtosis proche de 3).

    6.3 Moments d'une distribution et coefficients de Fisher

    Moments centrés

    Moment centré d'ordre k : Moyenne des écarts à la moyenne élevés à la puissance k.

    \[\mu_k = \frac{\sum_{i=1}^{N} (x_i - \mu)^k}{N}\]

    • \(\mu_1 = 0\) : la somme des écarts à la moyenne est nulle (propriété déjà vue).
    • \(\mu_2 = \sigma^2\) : le moment centré d'ordre 2 est la variance.
    • \(\mu_3\) : sert à mesurer l'asymétrie (skewness).
    • \(\mu_4\) : sert à mesurer l'aplatissement (kurtosis).

    Coefficient d'asymétrie de Fisher

    Coefficient de Fisher (\(\gamma_1\)) : Mesure normalisée de l'asymétrie d'une distribution.

    \[\gamma_1 = \frac{\mu_3}{\sigma^3}\]

    • \(\gamma_1 = 0\) : distribution symétrique (normale, uniforme).
    • \(\gamma_1 > 0\) : asymétrie positive (queue à droite).
    • \(\gamma_1 < 0\) : asymétrie négative (queue à gauche).

    En pratique, on considère qu'une distribution est symétrique si \(|\gamma_1| < 0,5\).

    Coefficient d'aplatissement de Fisher

    Aplatissement de Fisher : Reprend l'excès de kurtosis vu en §6.2.

    \[\gamma_2 = \frac{\mu_4}{\sigma^4} - 3\]

    • \(\gamma_2 = 0\) : distribution mésokurtique (normale).
    • \(\gamma_2 > 0\) : distribution leptokurtique (pointue, queues épaisses).
    • \(\gamma_2 < 0\) : distribution platykurtique (aplatie, queues fines).

    6.4 Courbe de Lorenz et indice de Gini

    Courbe de Lorenz : Représentation graphique de la concentration d'une variable (souvent les revenus ou les richesses). Elle compare le pourcentage cumulé de la population au pourcentage cumulé de la variable.

    Construction :

    1. Trier les individus par valeur croissante de la variable (ex : revenus).
    2. Calculer les fréquences cumulées de la population (\(p_i\)) et les fréquences cumulées de la variable (\(q_i\)).
    3. Reporter les points \((p_i, q_i)\) sur un graphique.

    Indice de Gini

    Indice (ou coefficient) de Gini : Mesure synthétique de la concentration, comprise entre 0 et 1.

    \[G = \frac{A}{A + B} = 2A = 1 - 2B\]

    • \(G = 0\) : égalité parfaite (tous les individus ont la même valeur).
    • \(G = 1\) : inégalité totale (un seul individu possède tout).
    • Plus \(G\) est proche de 1, plus la concentration est forte.

    Où \(A\) est l'aire entre la diagonale et la courbe de Lorenz, et \(B\) l'aire sous la courbe.

    Exemples : Indice de Gini des revenus — France ≈ 0,29, États-Unis ≈ 0,41, Afrique du Sud ≈ 0,63. Plus l'indice est élevé, plus les inégalités sont fortes.

    Glossaire

    Asymétrie (skewness)
    Mesure du déséquilibre d'une distribution. Asymétrie positive = queue à droite ; négative = queue à gauche.
    Aplatissement (kurtosis)
    Mesure de la concentration des données autour de la moyenne et dans les queues. Distributions leptokurtiques = pointues, platykurtiques = aplaties.
    Moment centré (µk)
    Moyenne des écarts à la moyenne élevés à la puissance k : µk = S(xi - ẍ)k / N.
    Coefficient de Fisher (g1, g2)
    Mesures normalisées de l'asymétrie (g1) et de l'aplatissement (g2). g1 = 0 pour une distribution symétrique.
    Indice de Gini
    Mesure d'inégalité entre 0 (égalité parfaite) et 1 (inégalité maximale). Calculé à partir de la courbe de Lorenz.

    7.1 Notion de série statistique à deux variables

    Série statistique double (X, Y) : Étude simultanée de deux caractères X et Y sur une même population. Chaque individu i possède un couple de valeurs \((x_i, y_i)\).

    Jusqu'ici, on a étudié une population selon un seul caractère (âge, taille, note...). On parle de série statistique simple. Lorsqu'on observe deux caractères simultanément sur la même population, on obtient une série statistique double, notée \((X, Y)\).

    Exemples concrets

    Variable X (explicative)Variable Y (expliquée)Sens probable de la liaison
    Taille (cm)Poids (kg)Positive : plus on est grand, plus on pèse
    Dépenses publicitaires (kDH)Chiffre d'affaires (kDH)Positive : plus on investit en pub, plus le CA augmente
    Heures d'étudeNote obtenuePositive : plus on étudie, meilleure note
    Prix d'un produitQuantité demandéeNégative : plus le prix monte, moins on achète
    Température extérieureConsommation de chauffageNégative : plus il fait chaud, moins on chauffe

    Objectif de l'étude bivariée

    L'objectif est de répondre à trois questions successives :

    1. Existe-t-il une liaison entre X et Y ? (question qualitative)
    2. Quelle est l'intensité de cette liaison ? (question quantitative → corrélation)
    3. Peut-on modéliser cette liaison par une équation et prévoir Y connaissant X ? (question de modélisation → régression)

    Analogie : Étudier une variable seule, c'est comme regarder la hauteur d'un arbre. Étudier deux variables, c'est regarder à la fois la hauteur ET l'âge de plusieurs arbres pour comprendre si les arbres plus vieux sont plus grands.

    Vocabulaire important : On distingue souvent la variable explicative (ou variable indépendante) X, qui est censée « expliquer » les variations, et la variable expliquée (ou variable dépendante) Y, dont on cherche à comprendre le comportement en fonction de X.

    7.2 Le tableau de contingence (tableau croisé)

    Tableau de contingence : Tableau à double entrée qui croise deux variables qualitatives (ou quantitatives discrètes). La case \((i, j)\) contient l'effectif \(n_{ij}\), c'est-à-dire le nombre d'individus pour lesquels \(X = x_i\) et \(Y = y_j\).

    Lorsque X prend p modalités \(x_1, x_2, \ldots, x_p\) et Y prend q modalités \(y_1, y_2, \ldots, y_q\), on construit le tableau suivant :

    X \ Y\(y_1\)\(y_2\)…\(y_q\)Total (\(n_{i.}\))
    \(x_1\)\(n_{11}\)\(n_{12}\)…\(n_{1q}\)\(n_{1.}\)
    \(x_2\)\(n_{21}\)\(n_{22}\)…\(n_{2q}\)\(n_{2.}\)
    ………………
    \(x_p\)\(n_{p1}\)\(n_{p2}\)…\(n_{pq}\)\(n_{p.}\)
    Total (\(n_{.j}\))\(n_{.1}\)\(n_{.2}\)…\(n_{.q}\)N

    Lecture des totaux marginaux :

    • \(n_{i.} = \sum_j n_{ij}\) → effectif total de la ligne \(i\) (tous les individus ayant \(X = x_i\))
    • \(n_{.j} = \sum_i n_{ij}\) → effectif total de la colonne \(j\) (tous les individus ayant \(Y = y_j\))
    • \(N = \sum_i n_{i.} = \sum_j n_{.j}\) → effectif total de la population

    Exemple détaillé

    On interroge 200 étudiants sur leur sport pratique (X) et leur satisfaction de vie (Y) :

    X \ YSatisfaitMoyenInsatisfaitTotal
    Sport régulier45201075
    Sport occasionnel35251575
    Aucun sport20151550
    Total1006040200

    Lecture : La case (Sport régulier, Satisfait) contient 45 : il y a 45 étudiants qui font du sport régulier ET qui se déclarent satisfaits. Le total de la première ligne est 75 : 75 étudiants font du sport régulier (quelle que soit leur satisfaction).

    7.3 Distributions marginales et distributions conditionnelles

    Distribution marginale de X

    Distribution marginale de X : Distribution de X seule, obtenue en « ignorant » Y. Elle est donnée par les effectifs marginaux en ligne \(n_{i.} = \sum_j n_{ij}\).

    Pour notre exemple, la distribution marginale de X est :

    XSport régulierSport occasionnelAucun sport
    Effectif \(n_{i.}\)75 (37,5%)75 (37,5%)50 (25%)

    Distribution marginale de Y

    Distribution marginale de Y : Distribution de Y seule, obtenue en « ignorant » X. Elle est donnée par les effectifs marginaux en colonne \(n_{.j} = \sum_i n_{ij}\).

    Pour notre exemple, la distribution marginale de Y est :

    YSatisfaitMoyenInsatisfait
    Effectif \(n_{.j}\)100 (50%)60 (30%)40 (20%)

    Distribution conditionnelle de Y sachant X = \(x_i\)

    Distribution conditionnelle : Distribution de Y restreinte aux seuls individus pour lesquels \(X = x_i\). Les effectifs sont les \(n_{ij}\) de la ligne \(i\), et l'effectif total est \(n_{i.}\).

    Exemple : Distribution de Y sachant « Sport régulier » (X = ligne 1) :

    Y | Sport régulierSatisfaitMoyenInsatisfaitTotal
    Effectif45201075
    Fréquence conditionnelle45/75 = 60%20/75 = 26,7%10/75 = 13,3%100%

    Interprétation : Parmi les sportifs réguliers, 60% sont satisfaits. Comparons avec les non-sportifs :

    Y | Aucun sportSatisfaitMoyenInsatisfaitTotal
    Effectif20151550
    Fréquence conditionnelle20/50 = 40%15/50 = 30%15/50 = 30%100%

    Comparaison : 60% des sportifs réguliers sont satisfaits contre seulement 40% des non-sportifs. Cette différence suggère une liaison entre sport et satisfaction, que les chapitres suivants permettront de quantifier précisément.

    Pourquoi les distributions conditionnelles sont-elles utiles ? Elles permettent d'étudier comment se comporte Y pour chaque valeur fixée de X. Si les distributions conditionnelles de Y sont très différentes selon la valeur de X, c'est que X et Y sont liées. Si elles sont identiques, X et Y sont indépendantes.

    7.4 Représentation graphique : le nuage de points

    Nuage de points (nuage statistique) : Lorsque X et Y sont des variables quantitatives, chaque individu est représenté par un point de coordonnées \((x_i, y_i)\) dans un repère orthonormé (X en abscisse, Y en ordonnée).

    Ce que le nuage de points permet de repérer

    • Tendance croissante (liaison positive) : les points montent de gauche à droite
    • Tendance décroissante (liaison négative) : les points descendent de gauche à droite
    • Forme linéaire : les points s'alignent approximativement selon une droite
    • Forme non linéaire : les points suivent une courbe (parabole, exponentielle...)
    • Absence de liaison : les points sont dispersés sans forme reconnaissable
    • Points aberrants : des points isolés, très éloignés du reste du nuage

    Représentation des différentes formes de liaison

    Avant de choisir un modèle d'ajustement, il est essentiel de reconnaître la forme du nuage de points. Voici les principales formes de liaison rencontrées en pratique :

    Forme Description Équation type Transformations possibles
    Linéaire Les points s'alignent selon une droite \(\hat{y} = ax + b\) Ajustement direct par MCO
    Exponentielle Croissance (ou décroissance) de plus en plus rapide. Les petits X donnent des Y proches, puis Y s'envole. \(\hat{y} = b \cdot a^x\) ou \(\hat{y} = b \cdot e^{kx}\) \(Y' = \ln(Y)\) → linéarisation en \(\ln(y) = \ln(b) + x\ln(a)\)
    Puissance Croissance ralentissante ou accélérée selon l'exposant. Les points dessinent une courbe passant par l'origine. \(\hat{y} = b \cdot x^a\) \(Y' = \ln(Y)\), \(X' = \ln(X)\) → \(\ln(y) = \ln(b) + a\ln(x)\)
    Logarithmique Croissance rapide au début, puis ralentissement progressif (courbe concave vers le bas). \(\hat{y} = a + b\ln(x)\) \(X' = \ln(X)\) → régression directe en \(y = a + b\ln(x)\)
    Parabolique (quadratique) Courbe en U ou en ∩. La relation croît puis décroît (ou l'inverse). \(\hat{y} = ax^2 + bx + c\) Variables auxiliaires \(X_1 = x\), \(X_2 = x^2\) → régression multiple
    Sigmol (logistique) Croissance en S : lente au début, rapide au milieu, puis saturation (plafonnement). \(\hat{y} = \frac{L}{1 + e^{-k(x-x_0)}}\) \(Y' = \ln\left(\frac{L}{y}-1\right)\) → linéarisation

    Description visuelle des principales courbes

    Courbe linéaire : Les points forment une bande étroite autour d'une droite. Exemple : relation entre heures d'étude et note obtenue.

    Y │ · · │ · · │ · · │ · · │· · └──────────── X (droite ascendante)

    Courbe exponentielle : Les points montent de plus en plus vite (ou descendent de plus en plus vite). Le nuage dessine une courbe qui s'incurve vers le haut. Exemple : croissance bactérienne, inflation, intérêts composés.

    Y │ · │ · │ · │ · │ · · │· · └──────────── X (accélération croissante)

    Courbe logarithmique : Les points montent rapidement au début puis la progression ralentit. Le nuage dessine une courbe concave vers le bas qui plafonne. Exemple : utilité marginale (satisfaction décroissante).

    Y │ · · · │ · │ · │· │· └──────────── X (décélération)

    Courbe parabolique : Les points dessinent un U (minimum) ou un ∩ (maximum). La relation s'inverse à un certain point. Exemple : performance en fonction de la température (optimum).

    Y │· · │ · · │ · · │ · (sommet) └──────────── X (parabole ouverte vers le haut)

    Courbe sigmoïde (logistique) : Les points dessinent un S. Croissance lente, puis rapide, puis plafonnement. Exemple : diffusion d'une innovation, croissance démographique avec capacité limite.

    Y │ ······ │ · │ · │ · │····· └──────────── X (forme en S)

    Règle pratique : Avant de calculer quoi que ce soit, toujours tracer le nuage de points. La forme visuelle guide le choix du modèle d'ajustement. Un mauvais choix de modèle (par exemple ajuster une droite à un nuage en forme de U) donnera des résultats trompeurs même si R² est élevé.

    Le point moyen du nuage

    Point moyen G : Point de coordonnées \(G(\bar{x}, \bar{y})\), où \(\bar{x}\) et \(\bar{y}\) sont les moyennes arithmétiques de X et Y respectivement. La future droite d'ajustement passera toujours par G.

    Propriété fondamentale : Quelle que soit la méthode d'ajustement choisie (moindres carrés, méthode de Mayer...), la droite de régression passe obligatoirement par le point moyen G(\(\bar{x}\), \(\bar{y}\)). C'est une vérification indispensable.

    8.1 Rappels : moyennes et variances marginales

    Avant de traiter de la liaison entre X et Y, il faut d'abord décrire chaque variable individuellement. Les paramètres de position et de dispersion vus en statistique à une variable s'appliquent à chacune des variables marginales X et Y.

    Moyennes arithmétiques

    Moyenne de X :

    \[\bar{x} = \frac{1}{N} \sum_{i=1}^{p} n_{i.} \cdot x_i\]

    Moyenne de Y :

    \[\bar{y} = \frac{1}{N} \sum_{j=1}^{q} n_{.j} \cdot y_j\]

    Si chaque individu est observé une fois (pas de tableau de contingence, mais une liste de couples), les formules se simplifient :

    \[\bar{x} = \frac{1}{N} \sum_{i=1}^{N} x_i \qquad \bar{y} = \frac{1}{N} \sum_{i=1}^{N} y_i\]

    Variances marginales

    Variance de X :

    \[V(X) = \sigma_X^2 = \frac{1}{N} \sum_{i=1}^{N} (x_i - \bar{x})^2 = \frac{1}{N}\sum x_i^2 - \bar{x}^2\]

    Variance de Y :

    \[V(Y) = \sigma_Y^2 = \frac{1}{N} \sum_{i=1}^{N} (y_i - \bar{y})^2 = \frac{1}{N}\sum y_i^2 - \bar{y}^2\]

    Les écarts-types marginaux sont simplement :

    \[\sigma(X) = \sqrt{V(X)} \qquad \sigma(Y) = \sqrt{V(Y)}\]

    Rappel de la formule simplifiée : La variance peut se calculer plus rapidement par \(V(X) = \overline{x^2} - \bar{x}^2\), c'est-à-dire « moyenne des carrés moins carré de la moyenne ». Cette formule évite de calculer chaque écart individuel.

    Exemple illustratif : calcul pas à pas

    Considérons un échantillon de 5 étudiants avec leurs notes en deux matières :

    Étudiant X (Maths) Y (Français)

    C810
    D1818
    E1012

    Étape 1 : Moyennes marginales

    \[\bar{x} = \frac{12+15+8+18+10}{5} = \frac{63}{5} = 12{,}6\]

    \[\bar{y} = \frac{14+16+10+18+12}{5} = \frac{70}{5} = 14{,}0\]

    Interprétation : En moyenne, les étudiants obtiennent 12,6 en maths et 14,0 en français. La moyenne en français est légèrement supérieure.

    Étape 2 : Variances marginales

    Calculons d'abord les carrés :

    Étudiant X \(x_i^2\) Y \(y_i^2\)
    A1214414196
    B1522516256
    C86410100
    D1832418324
    E1010012144
    Somme63857701020

    \[V(X) = \frac{857}{5} - (12{,}6)^2 = 171{,}4 - 158{,}76 = 12{,}64\]

    \[V(Y) = \frac{1020}{5} - (14{,}0)^2 = 204 - 196 = 8{,}0\]

    Écarts-types :

    \[\sigma(X) = \sqrt{12{,}64} \approx 3{,}56 \qquad \sigma(Y) = \sqrt{8{,}0} \approx 2{,}83\]

    Interprétation : Les notes en maths sont plus dispersées (\(\sigma \approx 3{,}56\)) qu'en français (\(\sigma \approx 2{,}83\)). Cela signifie que les performances en maths varient davantage d'un étudiant à l'autre.

    8.2 Définition et calcul de la covariance

    Covariance : Mesure de la variation conjointe de deux variables X et Y autour de leurs moyennes respectives.

    \[\operatorname{Cov}(X, Y) = \frac{1}{N} \sum_{i=1}^{N} (x_i - \bar{x})(y_i - \bar{y})\]

    Formule développée (plus pratique pour le calcul)

    \[\operatorname{Cov}(X, Y) = \frac{1}{N} \sum_{i=1}^{N} x_i \cdot y_i - \bar{x} \cdot \bar{y}\]

    On note \(\overline{xy} = \frac{1}{N}\sum x_i y_i\) la moyenne des produits. La formule se résume alors en :

    Formule mnémotechnique : \(\operatorname{Cov}(X,Y) = \overline{xy} - \bar{x}\bar{y}\) = moyenne des produits − produit des moyennes

    Explication intuitive

    La covariance calcule la moyenne des produits des écarts \((x_i - \bar{x})(y_i - \bar{y})\) :

    • Si \(x_i > \bar{x}\) et \(y_i > \bar{y}\) (les deux au-dessus de leur moyenne), le produit est positif.
    • Si \(x_i < \bar{x}\) et \(y_i < \bar{y}\) (les deux en dessous), le produit est aussi positif.
    • Si l'un est au-dessus et l'autre en dessous, le produit est négatif.

    Si les produits sont majoritairement positifs, X et Y varient dans le même sens → covariance positive.

    Exemple de calcul détaillé

    Reprenons les données de l'exercice 7.3 : X = {2, 3, 4, 5, 6} et Y = {20, 25, 30, 33, 40}.

    Étape 1 : Calculer les moyennes

    \(\bar{x} = (2+3+4+5+6)/5 = 4\)

    \(\bar{y} = (20+25+30+33+40)/5 = 148/5 = 29,6\)

    Étape 2 : Calculer la moyenne des produits

    \(\sum x_i y_i = 2 \times 20 + 3 \times 25 + 4 \times 30 + 5 \times 33 + 6 \times 40 = 40 + 75 + 120 + 165 + 240 = 640\)

    \(\overline{xy} = 640/5 = 128\)

    Étape 3 : Appliquer la formule

    \[\operatorname{Cov}(X,Y) = 128 - 4 \times 29{,}6 = 128 - 118{,}4 = 9{,}6\]

    Vérification par la formule de définition :

    i\(x_i\)\(y_i\)\(x_i - \bar{x}\)\(y_i - \bar{y}\)Produit
    1220−2−9,619,2
    2325−1−4,64,6
    343000,40
    453313,43,4
    5640210,420,8

    Somme des produits = 19,2 + 4,6 + 0 + 3,4 + 20,8 = 48

    Cov(X,Y) = 48/5 = 9,6 ✓

    8.3 Interprétation, propriétés et limites de la covariance

    Interprétation du signe

    Signe de Cov(X,Y)InterprétationExemple
    PositifX et Y varient dans le même sens (liaison positive)Taille et poids
    NégatifX et Y varient en sens opposés (liaison négative)Prix et quantité demandée
    Nul (≈ 0)Pas de liaison linéaire apparenteTaille et note à un examen

    Important : La covariance ne donne que le sens de la liaison, pas son intensité. Une covariance de 9,6 est-elle forte ? On ne peut pas en juger car la valeur dépend des unités de mesure.

    Propriétés fondamentales

    Propriété 1 : \(\operatorname{Cov}(X, X) = V(X)\)

    La covariance d'une variable avec elle-même est sa variance.

    Démonstration : \(\operatorname{Cov}(X,X) = \frac{1}{N}\sum(x_i - \bar{x})(x_i - \bar{x}) = \frac{1}{N}\sum(x_i - \bar{x})^2 = V(X)\).

    Propriété 2 : \(\operatorname{Cov}(X, Y) = \operatorname{Cov}(Y, X)\)

    La covariance est symétrique : l'ordre des variables n'a pas d'importance.

    Propriété 3 : \(\operatorname{Cov}(aX + b, cY + d) = a \cdot c \cdot \operatorname{Cov}(X, Y)\)

    La covariance est sensible aux changements d'échelle (multiplication) mais pas aux translations (addition de constantes).

    Interprétation : Si on mesure X en cm ou en m, la covariance change, car elle dépend des unités.

    Limite essentielle de la covariance

    Limite majeure : La covariance dépend des unités de mesure de X et de Y, ce qui rend impossible la comparaison de l'intensité de liaison entre différentes séries.

    Exemple : Cov(taille, poids) = 250 (en cm×kg) et Cov(prix, quantité) = 0,004 (en euros×unités). Peut-on dire que la première liaison est plus forte ? Non ! Les unités sont différentes, la comparaison n'a aucun sens.

    C'est pour résoudre ce problème que l'on introduit, au chapitre suivant, le coefficient de corrélation linéaire r, qui est un nombre sans unité et toujours compris entre −1 et +1.

    9.1 Coefficient de corrélation linéaire de Pearson

    Coefficient de corrélation linéaire de Pearson (r) : Mesure normalisée de l'intensité de la liaison linéaire entre deux variables quantitatives.

    \[r = \frac{\operatorname{Cov}(X,Y)}{\sigma(X) \times \sigma(Y)}\]

    Pourquoi introduire r alors qu'on a déjà la covariance ?

    La covariance (chapitre 8) donne le sens de la liaison mais pas son intensité, car sa valeur dépend des unités. Le coefficient r divise la covariance par le produit des écarts-types, ce qui élimine les unités et donne un nombre toujours compris entre −1 et +1.

    Analogie : La covariance, c'est comme dire « il y a 30 km entre ces deux villes ». C'est utile, mais on ne sait pas si c'est beaucoup ou pas sans connaître l'échelle. Le coefficient r, c'est comme dire « les deux villes sont à 90% de la distance maximale possible » : c'est une information normalisée, comparable.

    Propriétés de r

    • \(-1 \leq r \leq 1\) : r est toujours compris entre −1 et +1.
    • r est symétrique : \(r(X,Y) = r(Y,X)\).
    • r est invariant par changement d'unité et d'origine : \(r(aX+b, cY+d) = r(X,Y)\) si \(a > 0\) et \(c > 0\). Passer de cm à m, de °C à °F, ne change pas r.
    • \(r = \pm 1\) si et seulement si tous les points sont exactement alignés sur une droite.
    • On a la relation importante : \(r^2 = a \times a'\) où a est la pente de la régression Y en X et a' celle de X en Y.

    Exemple de calcul complet

    Reprenons nos données : X = {2,3,4,5,6}, Y = {20,25,30,33,40}.

    Nous avons déjà calculé : \(\operatorname{Cov}(X,Y) = 9{,}6\) ; \(V(X) = 2\) → \(\sigma(X) = \sqrt{2} \approx 1{,}414\) ; \(V(Y) = 46{,}64\) → \(\sigma(Y) = \sqrt{46{,}64} \approx 6{,}829\).

    \[r = \frac{9{,}6}{1{,}414 \times 6{,}829} = \frac{9{,}6}{9{,}657} \approx 0{,}994\]

    r ≈ 0,994 : la liaison est linéaire, positive et quasiment parfaite.

    9.2 Interprétation et propriétés de r

    Tableau d'interprétation de |r|

    Valeur de |r|Intensité de la liaison linéaireDescription
    |r| = 1ParfaiteTous les points sont exactement alignés sur une droite
    0,8 ≤ |r| < 1Très fortePoints très regroupés autour d'une droite
    0,5 ≤ |r| < 0,8Modérée à forteTendance linéaire visible mais avec dispersion
    0,2 ≤ |r| < 0,5FaibleTendance linéaire faible, nuage dispersé
    |r| < 0,2Quasi nullePas de liaison linéaire apparente

    Le signe de r indique le sens de la liaison :

    • r > 0 : liaison positive (Y tend à augmenter quand X augmente)
    • r < 0 : liaison négative (Y tend à diminuer quand X augmente)

    Coefficient de détermination R²

    Coefficient de détermination : Le carré du coefficient de corrélation.

    \[R^2 = r^2\]

    R² s'interprète comme la proportion de la variabilité totale de Y expliquée par la relation linéaire avec X.

    rR²Interprétation
    0,9940,98898,8% de la variation de Y est expliquée par X
    0,800,6464% de la variation de Y est expliquée par X
    0,500,25Seulement 25% expliquée, d'autres facteurs interviennent
    0,100,011% expliquée → ajustement linéaire quasi inutile

    Attention : R² mesure uniquement la part de variance linéairement expliquée. Si la relation est non linéaire (parabole, par exemple), R² peut être proche de 0 même si la liaison est forte ! C'est pourquoi il est indispensable de toujours examiner le nuage de points avant d'interpréter R².

    9.3 Corrélation et causalité

    Principe fondamental : La corrélation n'implique jamais la causalité ! Un coefficient r élevé indique une association statistique, mais ne prouve pas que X cause Y.

    Trois situations à distinguer

    1. Lien de causalité réel

    Dans certains cas, il existe bien un lien de cause à effet. Par exemple, la dose d'engrais appliquée (X) cause une augmentation du rendement agricole (Y). Mais même ici, il faut une expérimentation rigoureuse pour l'affirmer, pas simplement une corrélation.

    2. Variable cachée commune (facteur de confusion)

    Deux variables peuvent être fortement corrélées parce qu'elles sont toutes deux influencées par une troisième variable non observée.

    Exemple classique : Les ventes de glaces (X) et le nombre de noyades (Y) sont corrélées positivement (r élevé en été). Les glaces ne causent pas les noyades ! La variable cachée est la température estivale, qui augmente simultanément la consommation de glaces et la fréquence de la baignade.

    3. Corrélation fortuite (spurious correlation)

    Sur un échantillon particulier, on peut observer une corrélation entre deux variables qui n'ont aucun lien logique. Par exemple, le nombre de pirates dans le monde et la température mondiale sont statistiquement corrélés, mais évidemment sans aucune relation causale.

    La corrélation ne mesure que la liaison linéaire

    Point crucial : r ne mesure que la liaison linéaire. Deux variables peuvent être fortement liées par une relation non linéaire (parabole, exponentielle...) tout en ayant un coefficient r proche de 0.

    Exemple : Si Y = X² sur l'intervalle [−a, +a], le nuage forme une parabole parfaite (liaison déterministe), mais r ≈ 0 car la partie croissante compense la partie décroissante.

    Règle d'or

    Toujours suivre cette démarche :

    1. Tracer le nuage de points en premier.
    2. Vérifier visuellement la forme de la liaison (linéaire ? courbe ? nuage dispersé ?).
    3. Ensuite seulement, calculer r et l'interpréter à la lumière du graphique.

    L'ajustement linéaire : régression par la méthode des moindres carrés

    Droites de régression, méthode MCO, coefficient R²

    4 sections + exercices

    10.1 Principe de l'ajustement

    Ajustement : Trouver la courbe (ici une droite) qui « résume » le mieux la relation entre X et Y. Cette droite permettra de modéliser la liaison et de prévoir Y connaissant X.

    Vue d'ensemble des méthodes d'ajustement linéaire

    Il existe trois méthodes principales pour déterminer la droite d'ajustement \(\hat{y} = ax + b\) :

    Méthode Principe Quand l'utiliser ? Précision
    Points extrêmes Droite passant par le 1er et le dernier point Série très régulière, tendance monotone Faible (ignore les points intermédiaires)
    Méthode de Mayer Droite passant par les centres de gravité de deux sous-séries Série régulière, utilisation de tous les points Moyenne
    Moindres carrés (MCO) Minimise la somme des carrés des écarts Toute situation, surtout si points peu alignés Maximale (méthode optimale)

    Méthode des points extrêmes

    Principe : La droite d'ajustement est celle qui passe par le premier point \((x_1, y_1)\) et le dernier point \((x_n, y_n)\) de la série.

    Étapes de calcul :

    1. Identifier les coordonnées du premier point \((x_1, y_1)\) et du dernier point \((x_n, y_n)\).
    2. Calculer la pente : \(a = \frac{y_n - y_1}{x_n - x_1}\)
    3. Calculer l'ordonnée : \(b = y_1 - a \cdot x_1\) (ou \(b = y_n - a \cdot x_n\))
    4. Écrire l'équation : \(\hat{y} = ax + b\)

    Avantage : Très simple et rapide. Inconvénient : Ne tient compte que de deux points, ignore toute l'information des points intermédiaires. Sensible aux valeurs extrêmes.

    Exemple : Données : \((1{,}12),\ (2{,}18),\ (3{,}30),\ (4{,}51),\ (5{,}66),\ (6{,}75)\)

    Premier point : \((1{,}12)\) — Dernier point : \((6{,}75)\)

    \[\begin{aligned} a &= \frac{75 - 12}{6 - 1} = \frac{63}{5} = 12{,}6 \\[6pt] b &= 12 - 12{,}6 \times 1 = -0{,}6 \end{aligned}\]

    Équation : \(\hat{y} = 12{,}6x - 0{,}6\)

    Prévision pour \(x = 7\) : \(\hat{y} = 12{,}6 \times 7 - 0{,}6 = 87{,}6\)

    Méthode de Mayer

    Principe : Couper la série en deux sous-séries de taille égale (ou quasi égale). Calculer le point moyen (centre de gravité) de chaque sous-série. La droite de Mayer passe par ces deux points moyens.

    Étapes de calcul :

    1. Couper la série en deux groupes de taille comparable.
    2. Calculer \((\bar{x}_1, \bar{y}_1)\) : moyennes du premier groupe.
    3. Calculer \((\bar{x}_2, \bar{y}_2)\) : moyennes du second groupe.
    4. Calculer la pente : \(a = \frac{\bar{y}_2 - \bar{y}_1}{\bar{x}_2 - \bar{x}_1}\)
    5. Calculer l'ordonnée : \(b = \bar{y}_1 - a \cdot \bar{x}_1\)

    Avantage : Utilise tous les points de la série (contrairement à la méthode des points extrêmes). Inconvénient : Moins précise que les MCO car elle ne minimise pas explicitement les erreurs.

    Règle pour le découpage : Si le nombre de points est impair, prendre un point de plus dans la deuxième sous-série (la plus récente), car elle est plus représentative de la tendance actuelle.

    Exemple : Données : \((1{,}89),\ (2{,}97),\ (3{,}108),\ (4{,}120)\)

    Groupe 1 : \(\big\{(1{,}89),\ (2{,}97)\big\}\) → \(\bar{x}_1 = 1{,}5\) et \(\bar{y}_1 = 93\)

    Groupe 2 : \(\big\{(3{,}108),\ (4{,}120)\big\}\) → \(\bar{x}_2 = 3{,}5\) et \(\bar{y}_2 = 114\)

    \[\begin{aligned} a &= \frac{114 - 93}{3{,}5 - 1{,}5} = \frac{21}{2} = 10{,}5 \\[6pt] b &= 93 - 10{,}5 \times 1{,}5 = 93 - 15{,}75 = 77{,}25 \end{aligned}\]

    Équation : \(\hat{y} = 10{,}5x + 77{,}25\)

    Prévision pour \(x = 5\) : \(\hat{y} = 10{,}5 \times 5 + 77{,}25 = 129{,}75\)

    Méthode des moindres carrés ordinaires (MCO)

    On cherche une droite d'équation \(\hat{y} = ax + b\) telle que la somme des carrés des écarts verticaux entre les points observés et la droite soit minimale.

    Fonction-objectif à minimiser :

    \[S(a,b) = \sum_{i=1}^{N} (y_i - (ax_i + b))^2\]

    Les écarts \(y_i - \hat{y}_i = y_i - (ax_i + b)\) s'appellent les résidus : ce sont les « erreurs » de prédiction de la droite pour chaque point. La méthode MCO cherche la droite qui rend ces erreurs carrées collectivement les plus petites possibles.

    Analogie : Imaginez que vous lancez une fléchette sur un mur avec des points. Vous voulez tracer une droite qui passe au plus près de tous les points. La méthode MCO choisit la droite qui minimise la somme des carrés des distances verticales entre chaque point et la droite.

    Pourquoi minimiser les carrés ? On pourrait minimiser les écarts absolus, mais les carrés ont deux avantages : (1) ils pénalisent davantage les grands écarts que les petits, et (2) la résolution mathématique est simple (on obtient un système d'équations linéaires).

    10.2 Droite de régression de Y en X

    La résolution du problème de minimisation (en dérivant S par rapport à a et b et en annulant) conduit aux formules suivantes :

    Coefficient de régression (pente) :

    \[a = \frac{\operatorname{Cov}(X,Y)}{V(X)} = \frac{\overline{xy} - \bar{x}\bar{y}}{\overline{x^2} - \bar{x}^2}\]

    Ordonnée à l'origine :

    \[b = \bar{y} - a\bar{x}\]

    Équation de la droite de régression de Y en X :

    \[\hat{y} = ax + b\]

    Notée \((D_{Y/X})\).

    Interprétation des paramètres

    • La pente a : indique de combien Y varie en moyenne lorsque X augmente d'une unité. Si a = 4,8, chaque unité supplémentaire de X s'accompagne d'une hausse moyenne de 4,8 unités de Y.
    • L'ordonnée b : est la valeur estimée de Y quand X = 0. Attention : si X = 0 est en dehors du domaine observé, b n'a pas d'interprétation physique réaliste.

    Propriété fondamentale

    La droite de régression passe toujours par le point moyen \(G(\bar{x}, \bar{y})\). C'est une vérification rapide : en remplaçant x par \(\bar{x}\), on doit obtenir \(\hat{y} = \bar{y}\).

    Vérification : \(\hat{y}(\bar{x}) = a\bar{x} + b = a\bar{x} + (\bar{y} - a\bar{x}) = \bar{y}\). ✓

    Exemple de calcul complet

    Données : X = {2,3,4,5,6}, Y = {20,25,30,33,40}.

    Résultats déjà calculés : \(\bar{x} = 4\) ; \(\bar{y} = 29{,}6\) ; \(\operatorname{Cov}(X,Y) = 9{,}6\) ; \(V(X) = 2\).

    Étape 1 : Calculer la pente

    \(a = \operatorname{Cov}(X,Y) / V(X) = 9{,}6 / 2 = 4{,}8\)

    Étape 2 : Calculer l'ordonnée

    \(b = \bar{y} - a\bar{x} = 29{,}6 - 4{,}8 \times 4 = 29{,}6 - 19{,}2 = 10{,}4\)

    Étape 3 : Équation de la droite

    Interprétation : Chaque millier de DH supplémentaire investi en publicité s'accompagne, en moyenne, d'une hausse de 4 800 DH du chiffre d'affaires. L'ordonnée 10,4 signifie que même sans publicité, le CA serait estimé à environ 10 400 DH (interprétation à vérifier dans le contexte).

    Vérification : La droite passe-t-elle par G(4 ; 29,6) ?
    \(\hat{y}(4) = 4{,}8 \times 4 + 10{,}4 = 19{,}2 + 10{,}4 = 29{,}6 = \bar{y}\) ✓

    Prévision : Pour x = 7 (7 000 DH de pub), on estime :\(\hat{y} = 4{,}8 \times 7 + 10{,}4 = 33{,}6 + 10{,}4 = 44{,}0\) → soit environ 44 000 DH de CA prévu.

    10.3 Droite de régression de X en Y

    Si l'on souhaite exprimer X en fonction de Y (prévoir X connaissant Y), on obtient la droite \((D_{X/Y})\) :

    \[\hat{x} = a'y + b'\]

    avec \(a' = \frac{\operatorname{Cov}(X,Y)}{V(Y)}\) et \(b' = \bar{x} - a'\bar{y}\)

    Attention : \((D_{Y/X})\) et \((D_{X/Y})\) sont deux droites différentes en général (sauf si r = ±1, cas où elles sont confondues). Le choix dépend du sens de la prévision :

    • Utiliser \((D_{Y/X})\) pour prévoir Y connaissant X.
    • Utiliser \((D_{X/Y})\) pour prévoir X connaissant Y.

    Propriété remarquable

    Le produit des deux pentes est égal au carré du coefficient de corrélation :

    \[a \times a' = r^2\]

    Interprétation : Puisque \(r^2 \leq 1\), on a toujours \(a \times a' \leq 1\). Les deux pentes sont donc « dans le même ordre de grandeur » mais rarement égales.

    Exemple : régression de X en Y

    Avec les mêmes données : \(\operatorname{Cov}(X,Y) = 9{,}6\) ; \(V(Y) = 46{,}64\) ; \(\bar{x} = 4\) ; \(\bar{y} = 29{,}6\).

    \(a' = 9{,}6 / 46{,}64 \approx 0{,}2058\)

    \(b' = 4 - 0{,}2058 \times 29{,}6 \approx 4 - 6{,}092 = -2{,}092\)

    Équation : \(\hat{x} = 0{,}2058 \cdot y - 2{,}092\)

    Vérification : \(a \times a' = 4{,}8 \times 0{,}2058 = 0{,}988 \approx r^2 = 0{,}988\) ✓

    10.4 Coefficient de détermination R²

    Coefficient de détermination : Pour un ajustement linéaire, c'est simplement le carré du coefficient de corrélation.

    \[R^2 = r^2\]

    Interprétation

    R² est compris entre 0 et 1 et représente la proportion de la variabilité totale de Y qui est « expliquée » par la relation linéaire avec X.

    Analogie : Imaginez que la variation totale de Y (sa « variance ») est un gâteau à partager. R² vous dit quelle part du gâteau est « expliquée » par X, et (1 − R²) est la part qui reste inexpliquée (autres facteurs, hasard).

    Pour notre exemple : \(R^2 = 0{,}994^2 \approx 0{,}988\). Environ 98,8% de la variation du chiffre d'affaires est expliquée par les dépenses publicitaires. C'est un ajustement excellent.

    Quand R² est-il un bon indicateur ?

    • R² est pertinent quand le nuage de points montre une tendance linéaire.
    • Si le nuage est non linéaire (courbe), R² peut être trompeur (faible malgré une forte liaison).
    • R² ne dit rien sur la causalité : un R² élevé ne prouve pas que X cause Y.
    • R² ne dit rien sur la qualité des prévisions en dehors de l'échantillon.

    Résumé de la démarche complète (chapitres 7 à 10) :

    1. Tracer le nuage de points (chapitre 7).
    2. Calculer Cov(X,Y) pour connaître le sens de la liaison (chapitre 8).
    3. Calculer r pour mesurer l'intensité linéaire (chapitre 9).
    4. Si r est élevé, établir la droite de régression et calculer R² (chapitre 10).
    5. Utiliser la droite pour prévoir (avec prudence !).

    Chapitre 11

    Les ajustements non linéaires

    Modèles exponentiel, puissance et logarithmique

    5 sections + exercices

    11.1 Pourquoi des ajustements non linéaires ?

    De nombreux phénomènes ne suivent pas une évolution linéaire :

    • Croissance démographique ou financière (à taux constant → exponentielle)
    • Relations de type rendement décroissant (→ logarithmique)
    • Courbes de type racine ou parabole (→ puissance)
    • Décroissance radioactive, refroidissement (→ exponentielle décroissante)

    Lorsque le nuage de points dessine clairement une courbe (et non une droite), un ajustement affine serait inadapté et donnerait un r trompeur (proche de 0 malgré une forte liaison).

    La stratégie : linéariser puis réutiliser la MCO

    Principe général : On transforme les variables par un changement de variable approprié pour ramener la relation à une forme linéaire. On peut alors appliquer la méthode des moindres carrés du chapitre 10 aux variables transformées.

    Forme du nuageModèle suggéréChangement de variable
    Croissance/décroissance à taux constant\(y = b \cdot a^x\)\(Y' = \ln(y)\)
    Courbe type racine/parabole (x, y > 0)\(y = b \cdot x^a\)\(X' = \ln(x)\), \(Y' = \ln(y)\)
    Croissance rapide puis palier\(y = a \cdot \ln(x) + b\)\(X' = \ln(x)\)

    11.2 Ajustement exponentiel : \(y = b \cdot a^x\)

    Modèle exponentiel : Adapté lorsqu'on observe une croissance (ou décroissance) à taux constant, c'est-à-dire que les valeurs se multiplient approximativement par un facteur constant quand X augmente d'une unité.

    Linéarisation par le logarithme

    En prenant le logarithme népérien des deux côtés :

    \[\ln(y) = \ln(b) + x \cdot \ln(a)\]

    En posant :

    • \(Y' = \ln(y)\)
    • \(A = \ln(a)\)
    • \(B = \ln(b)\)

    On obtient la droite :

    \[Y' = A \cdot x + B\]

    Procédure de calcul

    1. Transformer Y en Y' = ln(Y) pour chaque observation.
    2. Effectuer la régression linéaire de Y' en X (méthode du chapitre 10) pour trouver A et B.
    3. Revenir aux paramètres d'origine : \(a = e^A\) et \(b = e^B\).

    Exemple détaillé

    Le CA (en kDH) d'une start-up sur 4 années : Y = {10, 20, 41, 79} pour X = {1, 2, 3, 4}.

    Étape 1 : Transformation

    Étape 2 : Régression de Y' en X

    \(\sum x_i Y'_i = 1 \times 2{,}303 + 2 \times 2{,}996 + 3 \times 3{,}714 + 4 \times 4{,}369 = 2{,}303 + 5{,}992 + 11{,}142 + 17{,}476 = 36{,}913\)

    Interprétation : Le chiffre d'affaires double approximativement chaque année (a ≈ 2). Le CA initial (année 0) serait d'environ 5 kDH (b ≈ 5).

    11.3 Ajustement puissance : \(y = b \cdot x^a\)

    Modèle puissance : Adapté lorsque X et Y sont tous deux strictement positifs et que le nuage évoque une courbe de type parabolique ou en racine carrée.

    Linéarisation

    En prenant le logarithme des deux côtés :

    \[\ln(y) = \ln(b) + a \cdot \ln(x)\]

    En posant \(X' = \ln(x)\) et \(Y' = \ln(y)\) :

    \[Y' = a \cdot X' + B\]

    où \(B = \ln(b)\).

    Procédure

    1. Transformer X en X' = ln(x) et Y en Y' = ln(y).
    2. Régression linéaire de Y' en X' → on obtient a et B.
    3. Revenir : \(b = e^B\).

    Quand l'utiliser ? Ce modèle est fréquent en physique (lois de puissance : \(F = k \cdot r^2\)), en biologie (relation surface/volume), en économie (courbes de rendement).

    11.4 Ajustement logarithmique : \(y = a \cdot \ln(x) + b\)

    Modèle logarithmique : Adapté lorsque Y croît rapidement puis se stabilise quand X augmente (rendements décroissants).

    Linéarisation

    Seule la variable X est transformée : on pose \(X' = \ln(x)\).

    On effectue directement la régression linéaire de Y en X' :

    \[y = a \cdot X' + b = a \cdot \ln(x) + b\]

    Pas de transformation sur Y nécessaire : a et b sont directement les résultats de la régression.

    Condition d'utilisation : Toutes les valeurs de X doivent être strictement positives (x > 0), car ln(x) n'est pas défini pour x ≤ 0.

    11.5 Choisir le meilleur ajustement

    Lorsque plusieurs modèles sont envisageables, on peut comparer leur coefficient de détermination R² (calculé sur les variables transformées) :

    1. Calculer le R² pour chaque modèle (exponentiel, puissance, logarithmique).
    2. Retenir le modèle dont le R² est le plus proche de 1.
    3. Vérifier que la forme du nuage est cohérente avec le modèle choisi.

    Mise en garde : Un R² élevé obtenu par pure coïncidence sur peu de points doit être interprété avec prudence. De plus, le R² des modèles transformés mesure l'ajustement sur les variables transformées, pas directement sur Y. Pour une comparaison rigoureuse, on peut calculer le R² « brut » en comparant les valeurs prédites \(\hat{y}_i\) aux valeurs observées \(y_i\).

    Chapitre 12

    Séries chronologiques, prévisions et synthèse générale

    Tendance, extrapolation, démarche complète et exercice de synthèse

    3 sections + exercice de synthèse

    12.1 Cas particulier : X représente le temps

    Une application très fréquente des chapitres précédents concerne les séries chronologiques, où X désigne une suite de dates ou de périodes (années, mois, trimestres) et Y la valeur observée d'un phénomène (ventes, production, population, température...).

    Série chronologique : Suite de valeurs Y₁, Y₂, ..., Yₙ observées à des moments successifs X₁ < X₂ < ... < Xₙ (généralement des périodes régulières).

    La tendance générale (trend)

    L'objectif est de modéliser l'évolution de Y dans le temps par une courbe (ou une droite) de régression de Y en X. On parle de tendance ou trend de la série.

    La démarche est exactement celle des chapitres 7 à 10 :

    1. Tracer le chronogramme (graphique de Y en fonction du temps).
    2. Si la tendance paraît linéaire → utiliser la régression linéaire \(\hat{y} = ax + b\) (chapitre 10).
    3. Si la tendance est non linéaire → utiliser un modèle exponentiel, puissance ou logarithmique (chapitre 11).

    Spécificité des séries chronologiques : On ne cherche généralement qu'un seul sens de régression (Y en fonction du temps X), car le temps est la variable explicative par nature. La régression de X en Y n'a ici aucun sens pratique (on ne peut pas « prévoir le temps en fonction des ventes »).

    12.2 Prévision par extrapolation

    Extrapolation : Estimer la valeur future de Y pour une période X₀ non observée en remplaçant X par X₀ dans l'équation de tendance.

    Précautions essentielles

    Règles à respecter :

    1. L'extrapolation n'est fiable qu'à court terme, proche de la période des données observées.
    2. Elle suppose que la tendance passée se maintient, ce qui peut être remis en cause par un changement structurel (crise, nouvelle réglementation, saturation du marché, innovation technologique...).
    3. Elle doit toujours être accompagnée d'un regard critique sur R² : un ajustement de mauvaise qualité rend la prévision peu crédible.
    4. Plus on s'éloigne des données observées, moins la prévision est fiable (risque croissant d'erreur).

    Interpolation vs Extrapolation

    InterpolationExtrapolation
    DéfinitionEstimer Y pour un X à l'intérieur de l'intervalle observéEstimer Y pour un X en dehors de l'intervalle observé
    Fiabilitégénéralement bonnedécroît avec l'éloignement
    Risquefaibleélevé (hypothèse de maintien de la tendance)

    12.3 Synthèse méthodologique générale

    Devant une série statistique à deux variables, voici la démarche complète à suivre, synthétisant les chapitres 7 à 12 :

    Les 7 étapes de la démarche complète :

    1. Construire le tableau (de contingence si les variables sont qualitatives/discrètes) et identifier les distributions marginales (chapitre 7).
    2. Tracer le nuage de points et repérer visuellement la forme de la liaison — croissante, décroissante, linéaire, non linéaire, absente (chapitre 7).
    3. Calculer les paramètres marginaux : \(\bar{x}\), \(\bar{y}\), V(X), V(Y) (chapitre 8).
    4. Calculer la covariance Cov(X,Y) pour connaître le sens de la liaison (chapitre 8).
    5. Calculer le coefficient de corrélation r et en interpréter la valeur et le signe (chapitre 9).
    6. Si la liaison paraît linéaire et r suffisamment élevé, établir l'équation de la droite de régression et calculer R² (chapitre 10). Sinon, choisir un modèle adapté (exponentiel, puissance, logarithmique) et comparer les R² (chapitre 11).
    7. Utiliser le modèle retenu pour interpoler ou extrapoler une prévision, en rappelant les limites de validité du modèle (chapitre 12).

    Moyen mnémotechnique : « Nuage → Cov → r → Régression → R² → Modèle → Prévision » (NCr²RMP).

    Étape 1 : Description du nuage

    Les couples (X, Y) sont : (1,12), (2,19), (3,28), (4,41), (5,58), (6,83).

    Le nuage montre une tendance croissante. De plus, les écarts entre valeurs successives de Y augmentent : 19−12=7, 28−19=9, 41−28=13, 58−41=17, 83−58=25. Cette accélération suggère une croissance non linéaire (possiblement exponentielle).

    Étape 2 : Calcul des paramètres marginaux

    \(\bar{x} = (1+2+3+4+5+6)/6 = 21/6 = 3{,}5\)

    \(\bar{y} = (12+19+28+41+58+83)/6 = 241/6 \approx 40{,}17\)

    \(V(X) = \frac{1+4+9+16+25+36}{6} - 3{,}5^2 = \frac{91}{6} - 12{,}25 = 15{,}167 - 12{,}25 = 2{,}917\)

    \(\sum y_i^2 = 144+361+784+1681+3364+6889 = 13223\)

    \(V(Y) = 13223/6 - 40{,}17^2 = 2203{,}83 - 1613{,}63 = 590{,}20\)

    \(\sum x_i y_i = 12+38+84+164+290+498 = 1086\)

    \(\operatorname{Cov}(X,Y) = 1086/6 - 3{,}5 \times 40{,}17 = 181 - 140{,}60 = 40{,}40\)

    Étape 3 : Coefficient de corrélation r

    \(\sigma(X) = \sqrt{2{,}917} \approx 1{,}708\)

    \(\sigma(Y) = \sqrt{590{,}20} \approx 24{,}30\)

    \(r = 40{,}40 / (1{,}708 \times 24{,}30) = 40{,}40 / 41{,}50 \approx 0{,}973\)

    r ≈ 0,973 : corrélation linéaire très forte. Un ajustement linéaire semble possible.

    Étape 4a : Ajustement linéaire

    \(a = \operatorname{Cov}(X,Y) / V(X) = 40{,}40 / 2{,}917 \approx 13{,}85\)

    \(b = \bar{y} - a\bar{x} = 40{,}17 - 13{,}85 \times 3{,}5 = 40{,}17 - 48{,}48 = -8{,}31\)

    \(\hat{y} = 13{,}85x - 8{,}31\) ; \(R^2 = 0{,}973^2 = 0{,}947\) → 94,7% de la variation expliquée.

    Étape 4b : Ajustement exponentiel

    Y' = ln(Y) : ln(12)=2,485 ; ln(19)=2,944 ; ln(28)=3,332 ; ln(41)=3,714 ; ln(58)=4,060 ; ln(83)=4,419

    \(\bar{Y'} = (2{,}485+2{,}944+3{,}332+3{,}714+4{,}060+4{,}419)/6 = 20{,}954/6 \approx 3{,}492\)

    \(\sum x_i Y'_i = 2{,}485+5{,}888+9{,}996+14{,}856+20{,}300+26{,}514 = 80{,}039\)

    \(\overline{xY'} = 80{,}039/6 \approx 13{,}340\)

    \(A = (13{,}340 - 3{,}5 \times 3{,}492) / 2{,}917 = (13{,}340 - 12{,}222) / 2{,}917 = 1{,}118 / 2{,}917 \approx 0{,}383\)

    \(B = 3{,}492 - 0{,}383 \times 3{,}5 = 3{,}492 - 1{,}341 = 2{,}151\)

    \(a_{\text{exp}} = e^{0{,}383} \approx 1{,}467\) ; \(b_{\text{exp}} = e^{2{,}151} \approx 8{,}59\)

    \(\hat{y} = 8{,}59 \times 1{,}467^x\)

    Calcul de R² exponentiel : \(\hat{y}_i\) = 12,61, 18,50, 27,14, 39,82, 58,42, 85,71. Les écarts aux valeurs observées sont très faibles, ce qui donne un R² brut ≈ 0,999.

    Étape 5 : Prévision pour l'année 7

    Avec le modèle exponentiel : \(\hat{y}(7) = 8{,}59 \times 1{,}467^7 \approx 8{,}59 \times 13{,}93 \approx 119{,}6\)

    Prévision : environ 120 000 abonnés pour l'année 7.

    Limites : (1) L'extrapolation d'une année au-delà des données observées est raisonnable mais comporte une incertitude. (2) La croissance exponentielle ne peut pas durer indéfiniment (saturation du marché, concurrence). (3) Le modèle est calibré sur seulement 6 points ; plus de données renforceraient la fiabilité.
